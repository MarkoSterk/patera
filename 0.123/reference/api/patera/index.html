patera¶

The top-level package: the application class, configuration, requests, responses and helpers.

add_request_observer ¶

add_request_observer(observer: RequestObserver) -> None

Calls observer(record) with a RequestRecord after every HTTP request, including those answered by the router (404, 405), static resources and failed requests. Observers run in the request's task once its response has been sent, so they must be quick and must not block; an observer that raises is logged and skipped.

default_exception_response ¶

default_exception_response(req: Request, exc: Exception) -> Optional[Response]

Fallback responses for exceptions without a registered handler.

BaseHttpException subclasses (abort(), RequestValidationError from @consumes, auth exceptions, ...) become a JSON response with the exception's status code.

Returns None for any other exception, which is then treated as an unhandled error (500). That includes a Pydantic ValidationError raised outside request-body validation: it is the server's data that failed. Override in the app class to customize.

register_middleware ¶

register_middleware(middleware_class: Type[MiddlewareBase], *, order: int | None = None) -> None

Registers a middleware class with the application.

Middleware instances are not created immediately. They are instantiated only when the HTTP application is built.

This allows extensions to register middleware during app initialization without forcing the HTTP app to build in CLI mode.

build ¶

build() -> None

Build the final app by wrapping self._app in all middleware.

Lower middleware order values are processed first and become outer middleware.

Registers exception handler classes with the application.
