# Getting started

This section takes you from an empty folder to a running Patera application.

1. [Installation](installation.md): install Patera and the optional extras you need.
2. [Quick start](quickstart.md): write a configuration, an application class and a controller.
3. [Project layout](project-layout.md): how Patera finds controllers, middleware and other
   components in your package.
4. [Running the application](running.md): the development and production servers and the
   `patera` command.

When the basics are in place, continue with the [Guide](../guide/index.md).

!!! tip "Complete example"

    A small, complete application lives in
    [`examples/basic_app`](https://github.com/MarkoSterk/Patera/tree/main/examples/basic_app)
    in the Patera repository.
