Extensions add optional features to Patera: SQL databases, migrations, authentication, caching, scheduled tasks, e-mail, declarative API clients, an admin dashboard and an AI interface.

The admin dashboard is installed with pip install patera-admin. It shows log records, database models, static files, task managers and e-mail clients.

The AI interface sends prompts to OpenAI-compatible APIs or Ollama. It can keep a chat history and add relevant documents to a question.
