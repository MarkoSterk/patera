Patera is a modular, async-first Python web framework. Applications are built from class-based controllers, injected services and typed configuration objects.

Install Patera with pip install "patera[dev]" or uv add "patera[dev]". It requires Python 3.13 or newer.

Start the development server with uv run patera dev. The production server, Granian, starts with uv run patera prod.
